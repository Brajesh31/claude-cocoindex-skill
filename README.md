# CocoIndex

A skill for building incremental data transformation and indexing pipelines with the CocoIndex framework.

## Capabilities

- Define Python-based indexing and ETL flows.
- Extract and transform data from files, cloud storage, and databases.
- Chunk documents, generate embeddings, and perform LLM-based extraction.
- Export results to vector databases, graph databases, and relational stores.
- Write custom transformation functions.
- Operate flows through the CLI or Python API.
- Support incremental processing and synchronization of changed data.

## Usage

Use this skill when building document indexing, semantic search, embedding, knowledge graph, or data synchronization pipelines. Define the source, transformations, destination schema, update frequency, and operational constraints before implementing a flow.

Refer to the official CocoIndex documentation and the detailed workflows in `SKILL.md`. Select optional package extras based on the connectors and features actually used.
